# Hallazgos iniciales — página actual

Fuente: https://www.dcmotorcompany.com/luxury-vehicles-for-sale-in-portland-or

La página actual es un inventario con navegación amplia, filtros avanzados, calculadora de pagos y una cuadrícula de vehículos. En la captura inicial se observa una composición muy densa: navegación superior extensa, filtros laterales ocupando mucho espacio horizontal y tarjetas de inventario con información poco jerarquizada. El viewport desktop muestra cuatro tarjetas y varios estados de carga vacíos debajo; los espacios blancos se perciben como resultados aún no cargados, no como una sección editorial intencional.

Para la propuesta de Onsidian Motors conviene separar descubrimiento editorial de inventario: un carrusel premium con una pieza principal y tarjetas secundarias debe comunicar curaduría, disponibilidad y contexto (modelo, precio, millaje, tren motriz o selling point), sin competir con los filtros. El carrusel debe tener navegación por teclado, controles visibles, progreso, swipe en móvil, altura estable, imágenes con object-fit y fallback visual; reducir el whitespace con un rail de contenido útil y un layout que se adapte en desktop, tablet y celular.

La calculadora, chatbot y appointment se mantendrán como experiencias de demo/mockup por ahora, con CTAs que expliquen o simulen el siguiente paso sin inventar persistencia. La propuesta backend debe cubrir inventario, leads, citas, chat, disponibilidad, notificaciones, analítica y seguridad.
